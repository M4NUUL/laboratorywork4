# Отчёт по лабораторной работе №4

## Цель

Спроектировать REST API и SPA с базой данных, аутентификацией, авторизацией, обработкой ошибок, безопасным хранением паролей и базовым CI/CD для предметной области безопасности спортивных сооружений и мероприятий.

## База данных и API

PostgreSQL хранит пользователей и инциденты. Пользователь имеет уникальный логин, bcrypt-хеш и роль. Инцидент хранит заголовок, категорию, зону, уровень угрозы, статус, ответственного, описание и время. Параметризованные SQL-запросы снижают риск SQL-инъекции.

API реализует регистрацию и вход, CRUD инцидентов, изменение статуса и административное управление пользователями. Ответы используют JSON и коды 200/201/400/401/403/404/409/500. Списки поддерживают пагинацию, поиск и фильтрацию.

## Аутентификация и безопасность

Пароль хешируется bcrypt с cost 12. После входа сервер выдаёт подписанный JWT сроком на два часа. Payload содержит идентификатор, логин и роль; защищённые маршруты проверяют подпись, issuer и срок. Администратор выполняет полный CRUD и управление пользователями; оператор просматривает данные и меняет статус. Helmet добавляет защитные заголовки, CORS ограничен адресом SPA, размер JSON ограничен 64 КБ.

Токен хранится в `localStorage`, что удобно для учебного SPA, но требует строгой защиты от XSS. Для промышленной версии предпочтительна пара короткоживущий access token + refresh token в `HttpOnly; Secure; SameSite` cookie с CSRF-защитой.

## Клиент и CI

React Router реализует `/login`, `/`, `/detail/:id`, `/add`, `/edit/:id`, `/admin/users`. Axios добавляет Bearer token и обрабатывает 401/403. Интерфейс показывает загрузку и сообщения ошибок. Workflow в `.github/workflows` собирает проект при push.

## Проверка

Проверяются: регистрация; вход; отказ при неверном пароле; список и карточка; создание/изменение/удаление; пагинация/фильтры; 401 без токена; 403 при недостаточной роли; сохранение в PostgreSQL. Для отчёта добавить скриншоты UI, Network, хеша в БД и CI.

## Заключение

Система реализует полный цикл защищённого веб-приложения: frontend, backend, PostgreSQL, REST, JWT, bcrypt, RBAC, ошибки и CI. Она развивает лабораторную №1, но ещё не включает полный аудит, OpenAPI, backup/restore и эксплуатационную документацию РГР.
